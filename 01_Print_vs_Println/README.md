Print vs Println

Objective
To understand the difference between print() and println() in Arduino.

Platform Used
Wokwi Arduino Simulator

What I Did
Created an Arduino project in Wokwi.
Used Serial.print() and Serial.println().
Ran the simulation.
Observed the output in the Serial Monitor.
Compared the output of print() and println().

Files
01_Print_vs_Println.ino - Arduino code
diagram.json - Wokwi circuit configuration
wokwi-project.txt - Wokwi project information

Result
print() prints the next output on the same line, while println() moves the next output to a new line.
